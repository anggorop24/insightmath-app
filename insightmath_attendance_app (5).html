Integrasi Google Sheets Backend

Hubungkan aplikasi ini dengan Google Apps Script Web App URL agar presensi dan data siswa tersimpan permanen di Google Sheets.

Panduan Pengaturan Google Apps Script:

1. Buat Google Sheets baru di Google Drive.

2. Buka menu Ekstensi > Apps Script.

3. Paste script backend dan klik Deploy > New Deployment.

4. Set akses "Who has access" ke Anyone.
